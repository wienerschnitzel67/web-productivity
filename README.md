# Web-Productivity
Small productivity management tool mainly written in PHP + JS.


# Features
- To-do list
  - Add, complete and remove tasks
  - Tasks are stored in a MySQL database

- (Pomodoro) Timer
  - 25 min countdown
  - Start, pause and reset the timer
  - Circular progress indicator

- Calendar
  - Automatically displays the current month
  - Automatically generates the correct number of days
  - Highlights the current day


# Planned features
- Previous / next month navigation
- User customization (e.g. light and dark mode)
- Music player (Spotify API?)
- Weather API
